# 单位经济测算 · 工单自动归档助手

> 示意测算：所有单价都用变量名表示，接入真实模型时只替换数字，公式不动。
> 写成具体厂商价格会让这份文档第二天就过期，而且会把"照抄别人的价格"变成默认动作。

---

## 变量定义

| 变量 | 含义 | 单位 | 样例取值 |
| --- | --- | --- | --- |
| `p_in` | 输入单价 | 元 / 千 token | 0.001 |
| `p_out` | 输出单价 | 元 / 千 token | 0.004 |
| `cache_hit_ratio` | 输入命中缓存的比例 | 比例 | 0.40 |
| `cache_discount` | 命中缓存后实际付费的比例 | 比例 | 0.50 |
| `input_tokens` | 单工单输入量（系统提示 + 标签手册 + 检索片段 + 历史工单） | token | 2600 |
| `output_tokens` | 单工单输出量（标签 + 理由） | token | 120 |
| `retrieval_cost` | 单次检索成本 | 元 / 次 | 0.002 |
| `retrieval_calls` | 单工单检索次数 | 次 | 2 |
| `tool_cost` | 单次工具调用成本 | 元 / 次 | 0.005 |
| `tool_calls` | 单工单工具调用次数 | 次 | 1 |
| `tickets_per_user_month` | 每客服每月处理的工单数 | 单 / 人 / 月 | 260 |
| `price_per_user_month` | 每客服每月的订阅价 | 元 / 人 / 月 | 99 |
| `active_users` | 试点期活跃客服数（回本周期按整个用户基数算） | 人 | 120 |
| `build_cost` | 一次性建设投入（人力 + 标注 + 语料） | 元 | 120000 |
| `support_cost_per_user_month` | 分摊到每人的支持成本 | 元 / 人 / 月 | 4 |

---

## 公式

```
计费输入 token = input_tokens × (1 - cache_hit_ratio + cache_hit_ratio × cache_discount)

模型成本（单工单）
  = 计费输入 token / 1000 × p_in
  + output_tokens / 1000 × p_out

单工单总成本
  = 模型成本
  + retrieval_calls × retrieval_cost
  + tool_calls × tool_cost

每用户月成本
  = 单工单总成本 × tickets_per_user_month

每用户月毛利
  = price_per_user_month - 每用户月成本 - support_cost_per_user_month

毛利率 = 每用户月毛利 / price_per_user_month

月度毛利总额 = 每用户月毛利 × active_users

回本周期（月）= build_cost / 月度毛利总额
```

回本周期按**整个用户基数**算，不是按单个用户——
单用户视角下的回本周期在有用户基数时是没有意义的数字。

## 代入样例取值后的结果

| 项 | 结果 |
| --- | --- |
| 计费输入 token | 2080 |
| 模型成本（单工单） | 0.0026 元 |
| 单工单总成本 | 0.0116 元 |
| 每用户月成本 | 3.01 元 |
| 每用户月毛利（已扣 4 元支持成本） | 91.99 元 |
| 毛利率 | 92.9% |
| 月度毛利总额（120 人） | 11038.8 元 |
| 回本周期 | 约 10.9 个月 |

---

## 怎么读这组数

1. **毛利率高得可疑，通常不是模型便宜，是定价没敢要**。真正的问题在下一条。
2. **回本周期 10.9 个月说明项目本身不危险，但定价定低了**：
   用户每月省下 260 单 × 3 分钟 = 780 分钟 = 13 小时，
   按 60 元/小时的客服综合成本算是 780 元，我们只收 99 元。
   定价应往「用户省下金额的 10%–30%」靠，即 78–234 元/月。
3. **成本侧的敏感项不是 token，是 `input_tokens`**：
   标签手册 + 历史工单检索占了输入的绝大部分，压缩它比换模型便宜得多。
   标签手册做成结构化前缀（固定部分可缓存）后，单工单成本还能再降 30% 以上。
4. **回本周期只在毛利为正时才有意义**。如果定价下调到让毛利接近 0，
   回本周期会趋于无穷——那时的正确结论是"停止放量"，不是"再等等"。
