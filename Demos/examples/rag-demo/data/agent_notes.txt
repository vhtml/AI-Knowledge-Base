# 第1页 智能体组成
Agent 由模型、工具、记忆和执行循环四部分组成。缺少任一部分都不能称为完整智能体。

# 第2页 工具调用规范
调用外部工具前必须校验参数类型与取值范围，并为单次任务设置最大步骤，防止无限循环。

# 第3页 RAG 回答原则
基于检索增强生成时，回答必须附带来源；资料库中找不到依据时，应明确说不知道，而不是猜测。

# 第4页 向量检索
检索阶段把问题和文档块都转成嵌入向量，用余弦相似度排序，只把得分最高的 top_k 块交给生成模型。

# 第5页 分块与元数据
过长文档按标题或固定长度切成块；每一块都要带上页码和标题，以便引用时能定位原文。

# 第6页 幻觉与拒答
模型在缺乏证据时容易产生幻觉。资料不足时必须拒答，禁止把常识或训练记忆冒充成本库事实。

# 第7页 记忆分层
短期记忆保存在当前对话上下文中；长期记忆写入向量库，跨会话按相似度召回相关笔记。

# 第8页 执行循环
智能体按观察、思考、行动、再观察的循环工作，直到任务完成或达到步数上限才停止。

# 第9页 来源引用格式
引用时应同时给出编号、页码和标题，例如 [来源1 p.3《RAG 回答原则》]，方便读者核对原文。

# 第10页 检索评测
用一批已知答案的问题做评测：看 top_k 结果里是否出现包含正确答案的片段，据此统计命中率。
