# LangGraph 深度教程 · 十七章

这个目录回答一个问题：**LangGraph 到底是什么、凭什么在 2026 年成了 Agent 工程的事实标准，以及怎么把它用到生产上。**

配套实验在 [`Demos/examples/langgraph_lab/`](../../Demos/examples/langgraph_lab/)，一章一篇笔记、一个能跑的实验，
最后产出一个**带持久化、有人在环路、可部署**的完整 Agent。

---

## 这套教程的前提假设

- 目标读者：会写 Python，但没系统用过 LangGraph 的人
- 目标产物：**能上生产的 Agent 图**——不是 demo，是带检查点、带审批、带流式、能部署的那种
- 时间投入：每章 1–2 小时；也可以当长期手册按需查阅
- 版本基线：**2026 年 11 月实测**（见下表），不是"某个博客里的 0.2"

---

| 包 | 版本 | 作用 |

| `langgraph` | 1.2.20 | 运行时：状态图、持久化、中断、流式 |
| `langgraph-checkpoint` | 4.3.1 | 检查点底层实现 |
| `langgraph-checkpoint-sqlite` | 3.1.3 | 落盘检查点（第 7 章用） |

| `langchain-core` | 1.8.0 | 消息、模型、工具抽象 |
| `langgraph-sdk` | 0.4.14 | 客户端 SDK（第 16 章用） |

| Python | 3.13.2 | — |

> **一条纪律**：涉及版本行为的结论，一律以上表和官方文档为准。
> LangChain 生态发版很勤（2026 年 1–11 月 LangGraph 就发了 30 多个稳定版），
> 网上流传的"LangGraph 2.0"至今**不存在**，1.x 线承诺到 2.0 之前不破坏兼容。

## 怎么跑实验

所有实验都在 `Demos/` 这层 Python 工程里，依赖用 `uv` 管理：

```bash
cd Demos/examples

# 跑某一章
uv run --project .. python -m langgraph_lab ch07

# 跑全部十七章
uv run --project .. python -m langgraph_lab all

# 自检（验证笔记与实验一一对应，且断言都还成立）
uv run --project .. python -m langgraph_lab selftest

# 列出所有章节
uv run --project .. python -m langgraph_lab list
```

### 两条运行路径

| 路径 | 触发方式 | 模型来源 | 用途 |
| --- | --- | --- | --- |
| 确定性路径 | 默认 | 脚本化假模型 | 学习与回归，断言严格、结果可复现 |
| 真实路径 | `--live` | `Demos/.env` 里的 OpenAI 兼容端点 | 看真模型怎么跑，断言只校验形状 |

```bash
# 第 7 章用真实模型再跑一遍
uv run --project .. python -m langgraph_lab ch07 --live

# 全部章节走真实路径
uv run --project .. python -m langgraph_lab live
```

真实路径读 `Demos/.env` 的 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`（仓库既有约定）。
没配也不要紧——会明确告诉你要补哪个变量，而不是在 HTTP 层报 401。

## 毕业标准

走完十七章，你手上应该有一个真实的 Agent 工程，满足全部条件：

- [ ] 能说清状态 schema 里每个键的归约器语义，以及为什么是这个语义
- [ ] 有一条带检查点的线程，进程重启后能从上次中断处继续
- [ ] 有人工审批环节，能暂停、能改、能恢复
- [ ] 有流式输出，且知道自己用的是哪种事件投影
- [ ] 有一份 `langgraph.json`，能本地起服务、能被 Studio 连上
- [ ] 有一套评测集，改动前后能跑出可比对的分数
- [ ] 节点的重试、超时、降级策略是**按失败类型选的**，不是一把梭

第 17 章的实验输出就是这份毕业作品的自检清单。

## 一句话结论

> **LangGraph 的本质不是"画流程图"，而是把 Agent 变成一个可持久化、可中断、可恢复的状态机。**
> 你画的不是流程，是**状态与状态之间的转移契约**——图能跑通只说明连线对，
> 状态设计对了，图才敢放到生产上。
