# AI 产品经理 · 八周系统教程

这个目录回答一个问题：**怎么从零成为一个能独立把 AI 想法变成可上线产品的产品经理——而且每一章都留下可检查的产出物。**

每章末尾都有一个**纸上练习**：用你自己的真实数据，照本章的方法做一遍，
最后产出一份能给别人看的东西。八周走完，你手上是一份**能直接拿去评审的完整产品方案包**。

---

## 这套教程的前提假设

- 目标读者：有产品或技术任一背景，但没系统做过 AI 产品的人
- 目标产物：**一份完整的 AI 产品方案包**——PRD + 评测集 + 指标字典 + 单位经济 + 风险登记册
- 时间投入：每周 6–8 小时（两章 + 两个纸上练习），共 8 周；也可当长期手册按需查阅
- 适用对象：做 C 端工具、企业服务、内部效率工具的 PM，不限行业

### 一条纪律：方法论不追版本，事实必须标日期

模型每几周换一版、厂商每几个月改一次价。本教程的处理方式：

| 内容类型 | 处理方式 |
| --- | --- |
| 方法论、判据、框架 | 长期有效，按季度复核 |
| 具体版本、价格、法规时点 | 写明来源链接 + "核实于 2026-11" |
| 需要精确数值的地方 | 留成**可替换变量**（如 `P_in`），配估算方法，不写死数字 |

第 12 章的单价、第 13 章的合规时点都是按这个规矩处理的——**引用之前请自己复核一遍**。

## 怎么练

**这套教程没有配套代码，所有练习都是纸上的。** 不是偷懒，是刻意的：
AI 产品经理要练的是判断，而判断只能对着**自己的真实数据**练——
示例数据能验证你算对了，验证不了你的判断。

每个「本章练习」小节都长这样：

| 段落 | 内容 |
| --- | --- |
| 输入 | 你手上真实的东西：某个功能、某段对话、某份文档、某条流程 |
| 步骤 | 照本章的方法做，通常三到五步 |
| 产出 | 一份具体的、能给别人看、能存档的东西 |
| 怎么算做对 | 2–3 条**可检查的判据**，不是"你理解了本章" |

**唯一需要的工具**是笔记结构校验器，它检查的是文档有没有坏（链接失效、表格错位、
围栏没闭合），不是替你做练习：

```bash
python3 scripts/check_ai_product_notes.py   # 在仓库根目录执行
```

详见 [`scripts/check_ai_product_notes.py`](../../scripts/check_ai_product_notes.py)。

**一条纪律**：练习不写完，第三章的判据就只是你读过的文字。
**写下来的东西才算数**——包括那个被否掉的场景，和那份你觉得"我大概知道"的风险清单。

## 毕业标准

走完八周，你手上应该有一个真实的 AI 产品方案包，满足全部条件：

- [ ] 能力雷达里最弱的三项，有明确的三个月补齐动作
- [ ] 能用四条判据否掉一个"看起来很酷"的 AI 需求，并说清为什么
- [ ] 有一张竞品地图，标着自己的坐标和一句话差异点
- [ ] 定价锚点是算出来的，不是拍出来的；知道每用户月成本上限在哪
- [ ] 有一份信任式回答模板，含来源、置信表达、拒答出口、可撤销路径
- [ ] 自动化等级有决策依据，工具清单里每个工具都标了权限档位
- [ ] 有评测集和回归门禁：改动前后能跑出可比对的分数
- [ ] 单位经济表算得出毛利和回本周期
- [ ] 风险登记册覆盖幻觉 / 越权 / 偏见 / 隐私 / 滥用，每条有缓解措施
- [ ] 有一个可判伪的北极星指标，外加护栏指标与诊断指标
- [ ] PRD、评测集、指标、成本、风险五份产物齐全，能直接拿去评审

五份产物的**空模板**在 [附录-B 模板库](附录-B-模板库.md)：
模板 6 单位经济、模板 7 AI PRD、模板 8 评测集、模板 9 指标字典、模板 10 风险登记册。
第 15、16 章的练习会带你逐份填完。

## 这套教程的三条纪律

1. **先判场景，再谈方案。** 大多数 AI 项目死于场景选错，不是死于模型不够强。
2. **质量用数据说话。** "感觉变好了"不是结论，第 11 章的门禁才是。
3. **成本是产品约束，不是财务问题。** 第 12 章的表必须在 PRD 之前画。

## 一句话结论

> **AI 产品经理的核心能力，是在模型不确定的前提下，把价值、质量、成本、风险这四本账同时算清楚。**
> 十六章就是这四本账的目录：第 2–10 章算价值，第 11–12 章算质量与成本，
> 第 13–14 章算风险与度量，第 15–16 章把它们合成一份能评审的方案。
