# Vibe 知识动画 · 系统教程

这个目录回答一个问题：**"Vibe 知识"这种短视频到底是怎么做出来的，怎么把它做成一条可复现的产线。**

先说清楚"它是什么"。这是抖音上 `#Vibe知识大赏` 那个话题下的片型：
三五分钟，16:9 横屏，没有真人、没有实拍、没有旁白，
屏幕上全是不断生长、拆解、重组的文字和图形，
底部一行字幕慢慢亮起来，字幕说到什么，屏上就在发生什么。
据 2026 年 11 月的公开报道，该话题已有 18.6 万人参与、累计播放 43.8 亿次。

它的制作方式在这两年发生了根本变化：**画面不再由动画师逐帧画出来，
而是由大模型写一段 Canvas/JavaScript 代码，再由浏览器逐帧渲染成视频。**
一个 5 分钟的传统动画曾需要 4–5 人花 2–4 周；现在一个人 + 一套代码，
几天能出一条。

配套实验在 [`Demos/examples/vibe_film_lab/`](../../Demos/examples/vibe_film_lab/)，
一章一个主题、一篇笔记、一个能跑的实验，
最后产出一条**真实渲染出来的 27 秒样片**。

---

## 这套教程的前提假设

- 目标读者：会用一点 Python 和 Markdown，能看懂 JavaScript 的人
- 目标产物：**一条自己做得出来的知识短片**，而不是"看过教程"
- 技术路线：**主线走代码渲染**（Canvas + JS + ffmpeg），同时给出现成工具的对照与选型
- 成片形态：横屏 1920×1080、30fps、2–5 分钟、无人声字幕科普

不假设你会前端。实验里的 `film.js` 是逐行注释过的，读得懂 JS 就能改。

## 怎么跑实验

所有实验都在 `Demos/` 这层 Python 工程里，依赖用 `uv` 管理：

```bash
cd Demos/examples

# 跑某一章
uv run --project .. python -m vibe_film_lab ch07

# 跑全部 12 章
uv run --project .. python -m vibe_film_lab all

# 自检（不依赖 pytest）
uv run --project .. python -m vibe_film_lab.selftest
```

除渲染那几章外，实验全部**离线运行**：不联网、不消耗 token、不调用模型。
第 7、10 章需要本机装有 Chrome/Chromium/Edge 和 ffmpeg，没装会打印"跳过"并继续。

## 毕业标准

走完十二章，你手上应该有一条**真正渲出来的片子**，满足全部条件：

- [ ] 字幕稿过了体检：句长 ≤ 24 字、停留 3–5 秒、一句最多染一处颜色
- [ ] 分镜表过了体检：三问齐、"不画"占约五分之一、每镜只改一处
- [ ] 事实表双向核对通过：屏上每个数字有出处，示意的地方写明了
- [ ] `render(t)` 是纯函数：同一时刻渲两遍逐字节一致
- [ ] 字幕起点和拍点命中率 ≥ 75%
- [ ] 八道终检门槛全过，人工确认项逐条勾过
- [ ] 成片规格是 1920×1080、30fps，帧数 = 时长 × 帧率

毕业作品就是 `Demos/examples/vibe_film_lab/capstone/fourier_C/`——
一条讲傅里叶变换直觉的 28 秒短片，从分镜表到 MP4 全套齐活。

## 一句话结论

> Vibe 知识动画的门槛从来不在"画得多好看"，而在**能不能把一句话变成屏上真实发生的一下**。
> 模型把生成本降到近乎免费之后，这个门槛从"审美"变成了"工程"——
> 而工程是可以被写成规矩、被机器检查、被反复复现的。

这就是这套教程要交付的东西：把一个靠手感的活儿，拆成一串能验收的步骤。
