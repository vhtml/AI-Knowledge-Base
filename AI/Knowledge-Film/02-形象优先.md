# 02 · 形象优先：先找形象，再写文案

> **这篇要回答**：一句抽象的话怎么变成屏上真实发生的一下？
> 答案不是"配一张图"，是**改那句话**。

---

## 1. 顺序错了，后面全废

Vibe 知识的信息通道只有字幕，所以画面必须承担"演示"的职责。
这一条直接决定了写作顺序：

```
✅ 先找形象 → 再写句子 → 排时间轴 → 画
❌ 先写句子 → 找配图 → 配音 → 对轴
```

第二种顺序在传统解说里也常见，但它成立的前提是"画面只是佐证"。
在这里不成立——字幕说到"砍掉一半"，屏上必须**真的砍掉一半**；
做不到的话，观众会读出"这句话和这个画面没关系"。

---

## 2. 什么叫"形象"

形象 = **观众认识的东西** + **它能做的事**。

| 不是形象 | 是形象 |
| --- | --- |
| 抽象概念、机制、原理 | 一个能摸到的东西 |
| 关系、影响、趋势 | 两个东西摆在一起比 |
| 规律、效应、维度 | 一把尺子、一张表、一条线 |
| "很重要""很广泛" | 一个具体的数量 |

判定标准很朴素：**你想画它的时候，手第一反应是什么？**
如果答案是"画个箭头"或者"写几个字"，那不是形象。

同一批抽象概念，换个说法就立刻能画：

| 抽象说法 | 能画的说法 |
| --- | --- |
| 复利 | 一笔钱在滚，每过一年变厚一圈 |
| 信息熵 | 一堆字母被越搅越乱，能复原的顺序越来越少 |
| 幸存者偏差 | 机场里看到的老飞行员，没看到回不来的人 |
| 卷积 | 两摞数叠在一起，加起来 |
| 傅里叶 | 一团乱线裂成三条简单���波 |

最后一行是本课毕业作品《把复杂拆成简单》的主题。
它的"形象"是**波**：听不见，但一条线就能画；能拆、能叠、能数。
选它当例子，是因为它是少数"概念本身就是图形"的抽象概念——
而这样的概念最适合做这类片子。

---

## 3. 六种画法

找到形象之后，还要决定**怎么摆**。实战里反复出现的画法就六种：

| 画法 | 干什么用 | 例子 |
| --- | --- | --- |
| 位置排布 | 把几个东西摆在一张台面上，讲关系 | 三根波并排，各自标频率 |
| 时间推进 | 一件事往前走一步，讲它怎么变的 | 乱线裂成三条波 |
| 比例分割 | 把整体切一块出来，讲它在整体里的位置 | 把频率从低到高排开成频谱 |
| 对照比较 | 两个东西并排，讲差别 | 三条波叠回一条乱线 |
| 代入体验 | 让观众自己经历一遍 | 你替别人做了一百次决定 |
| 道具实验 | 拿一个物件做实验，结果看得见 | 把一段声音拆开看 |

选画法的顺序：**先看这句话在讲什么关系**。
讲"谁和谁"→ 位置排布；讲"怎么变的"→ 时间推进；
讲"占多大比例"→ 比例分割；讲"和以前比"→ 对照比较。

不要一上来就想"用什么动画炫技"。六种画法里没有一种是炫技，
它们都是**把关系摆出来**的方式。

---

## 4. 可画性检验

写完一句字幕，问三个问题：

1. **这是什么？**——用日常的词说出来，不许用术语。
   （"傅里叶级数"✗ → "一堆正弦波"✓）
2. **它在干什么？**——一个动词。
   （"展示"✗ → "裂开"✓）
3. **观众明白了什么？**——一句人话结论。
   （"这说明数学很美"✗ → "复杂的东西能拆成简单的"✓）

三问有一问答不上来，这句就画不出来。

把这个判定写成一个**启发式词表**：
句子里有具体物件、有可演动词、长度放得下一行，三条都满足才算"画得出来"。
它不是语言学判断，是给写稿人当草稿纸用的——
凡是抽象名词堆砌、动词缺失的句子，一律打回重写。

### 四种典型的"画不出来"

| 症状 | 例句 | 病根 | 改法 |
| --- | --- | --- | --- |
| 抽象名词堆砌 | "这是一个非常抽象的概念" | 没有可画的东西 | 换成观众熟悉的东西 |
| 历史/自指开头 | "在 19 世纪，数学家傅里叶提出了……" | 信息对观众无用 | 从现象切入，历史放片尾 |
| 叮嘱观众 | "这个话题非常重要，请大家认真看完" | 自说自话 | 删掉，直接讲事 |
| 超长句 | 40 字一句 | 一行放不下，5 秒读不完 | 拆成 2–3 句 |

## 5. "不画"也是画法

有三种句子**故意不配图**：

| 句子类型 | 例子 | 为什么 |
| --- | --- | --- |
| 提问 | "那问题来了：这是巧合吗" | 提问画面一动，观众就去找答案了 |
| 命名 | "这叫傅里叶变换" | 名字是词，配图没有意义 |
| 结论 | "复杂 = 简单相加" | 结论是抽象判断，硬配图会削弱它 |

经验值：**"不画"占全片约五分之一**。
一个都没有，说明把结论也画了——画面会被塞满，观众失去呼吸的余地；
占了一半，说明没找到形象，只是把"不画"当成了偷懒的借口。

这条在第 5 章的分镜体检器里是一个可计算的门槛。

---

## 6. 自查

每写一句字幕，过一遍：

- [ ] 屏上是什么？我能立刻画出来吗？
- [ ] 它在干什么？是一个动词吗？
- [ ] 观众看这一镜，明白什么？
- [ ] 句子里每个名词，屏上都能找到吗？
- [ ] 这一句是不是应该"不画"？

---

## 7. 和实验的对应

这一章没有配套实验——"能不能画出来"是写稿时的判断，不是体检项。

不过它的两条结论落到了别处：
"不画"的比例（第 5 章的分镜体检器会算），
以及分镜表的三问（第 5、11 章都会查）。

上面那四句坏文案就是现成的自测题：写完一句字幕，
拿上面那张表逐条对一遍，对不上就重写。

---

**一句话**：画不出来的句子，改句子。
给一句抽象话配一张抽象图，是这类片子最快的一种死法。
