# 附录-A · 术语表

按字母/拼音顺序排，便于检索。

---

**Vibe 知识 / Vibe 知识大赏**
抖音上的一类知识科普短视频片型：16:9 横屏、2–5 分钟、无人声、字幕即内容、
画面由代码（Canvas/JavaScript）逐帧渲染而成。本教程讲的���是这一支。

**片型**
一类视频的形态规范（画幅、时长、帧率、声音、字幕规则）。
"做 Vibe 知识"就是"满足这一套形态规范"。

**形象（metaphor）**
观众认识的具体东西，加上它能做的一件事。
抽象概念在找到形象之前不能写稿。

**可画性检验**
判断一句话能不能被画出来的三问：这是什么 / 它在干什么 / 观众明白了什么。

**六种画法**
位置排布、时间推进、比例分割、对照比较、代入体验、道具实验。
决定一个概念用哪种空间关系讲得清。

**事实表**
写稿之前准备的表：事实、上屏的值、类型（史实/定理/示意）、出处。
每个上屏的数字都必须在这张表里。

**示意**
为了讲清道理而编的、不作精确测量用的数字（如演示用的 220 Hz）。
必须显式标注，否则观众会当成真实数据。

**双向核对**
事实检查的两个方向：字幕 → 事实表（防编造）、事实表 → 字幕（防遗漏）。

**分镜表**
一句字幕一行的施工图，七列：字幕 / 画法 / 屏上是什么 / 它在干什么 /
屏上的小字 / 观众明白了什么 / 声音。

**三问检验**
分镜表级别的检查：这是什么、它在干什么、观众明白了什么。

**画与不画**
提问、命名、结论三类句子故意不配图。"不画"应占全片约五分之一。

**夜曲（World C）**
适用于抽象概念、看不见的机制的一套外观：蓝黑夜空、细星点、大字细宋、
声音完全由代码合成。

**寓言（World B）**
适用于心理、行为类逻辑的一套外观：暖纸色、手绘边框、每场一幅程序画、
配用户提供的 BGM。最费工。

**颜色语义锁定**
金色 = 关键词，玫红 = 反直觉的点，青色 = 数值。
一部片子里一个颜色只表达一个意思，全片不破例。

**render(t)**
把时间 t 映射到一帧画面的纯函数。整条渲染管线的地基。

**seek(t)**
把 t 交给 render(t)。渲染页、联络表、逐帧导出走的是同一条路径。

**确定性**
同一个 t 渲两遍，逐字节一致。不一致说明画面里混进了状态。

**确定性伪随机（seeded）**
用索引做种子的伪随机函数。用它画星点、噪点，保证每帧位置固定。

**联络表（contact sheet）**
在若干时刻各截一帧，拼成一张图。一眼看完一条片子的风格一致性。

**转场检查图（motion sheet）**
在一小段时间里连取 N 帧拼成一张图，用来看转场怎么接的。

**时间轴**
字幕在片中的起止时间。停留时长按字数算，句间留呼吸间隙。

**卡点**
字幕起点和画面变化落在音乐的拍点上。命中率 75%–85% 比较自然。

**小节线**
BGM 的乐句单位（通常 4 拍）。段落开头对到小节线，比对到拍点更有乐感。

**纯画面段落**
没有字幕、只有画面的时段。每 20–30 秒留一段，让观众喘口气。

**事件音**
画面发生变化时登记的一个短音，由代码合成，不依赖采样库。

**登记（register）**
画面代码调用 `fr.sfx(时刻, 名字)` 把声音事件写下来，混音时按登记合成。
声音和画面对得上是结构保证的。

**帧数预算**
`时长 × 帧率`。渲染成本 = 帧数 × 单帧耗时。

**逐帧渲染**
逐帧截图再编码。不录屏，结果可复现。

**终检门槛**
交片前的八道检查：讲解、画与不画、结构、字幕、画面、节奏、事实、技术。

**静音遮字幕看一遍**
终检的第一遍。只看画面，判断每一段在讲什么。

**只读字幕读一遍**
终检的第二遍。只读文字，判断文案通不通顺。

**画幅**
视频的宽高比。本片型统一 16:9 横屏。

**yuv420p**
H.264 的主流兼容像素格式。必须用，否则部分平台会黑屏。

**faststart**
把 MP4 的 moov 原子搬到文件头，别人点开就能直接播。
