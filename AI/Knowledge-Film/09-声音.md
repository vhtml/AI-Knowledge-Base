# 09 · 声音：没有人声，节奏靠声音撑

> **这篇要回答**：一句旁白都没有，声音还能干什么？
> 答案：**登记事件**，让声音和画面对齐。

---

## 1. 无人声是限制，也是自由

没有旁白意味着观众不会"听"，只会"看 + 读"。
这释放了声音的全部带宽去干一件事：**标记节奏**。

一支 2–5 分钟的无人声片子，声音通常只有两层：

| 层 | 是什么 | 来自哪 |
| --- | --- | --- |
| 底层 | BGM | 用户提供（一路）或不用 |
| 表层 | 事件音 | **代码合成**（几十分之一秒的短音） |

观众不会去听"这是什么声音"，他们只会感觉到"这里发生了一件事"。

---

## 2. 事件音的四种用法

| 事件 | 声音 | 为什么 |
| --- | --- | --- |
| 一次变化 | 一声短音（中频） | 屏上东西动了，声音同步标记 |
| 推拉 | 上滑音 | 镜头在动，音高往上走 |
| 落定 | 低音 | 东西停了，声音落下来 |
| 提问 | **不出声** | 留白本身就是信号——观众听不到声音，就知道该想了 |

**提问那镜不出声**是这套做法里最讲究的一条。
声音突然消失，观众会下意识屏住呼吸——这正是提问想要的效果。

实测样本里，提问镜（"那问题来了：这是巧合吗"）在事件音表里是空的，
而提问之后还留了 2 秒纯画面：问号挂在屏上，声音也是安静的。
然后答案那句"不"配上低频落定音，效果比任何音效都强。

---

## 3. 事件音是"登记"出来的，不是"配"上去的

这是关键的技术差别：

```javascript
// 画面里发生变化的那一行，顺手登记一个声音事件
fr.sfx(t, 'split');
```

混音的时候，脚本去读这份登记，按时刻合成对应的事件音。

所以：

- 声音和画面对得上是**结构保证**的，不是靠人手对；
- 改画面时声音自动跟着改；
- 不需要任何采样库，**没有版权问题**。

手工后配的做法是：渲完视频，看一遍，在时间轴上打点。
2 分钟的片子打 30 个点，多半会错三个。

---

## 4. 合成事件音

用 ffmpeg 的正弦源就能合成，不需要任何素材：

```bash
ffmpeg -y \
  -f lavfi -i "sine=frequency=520:duration=0.14" \
  -f lavfi -i "sine=frequency=760:duration=0.12" \
  -filter_complex "[0:a]adelay=7800|7800,volume=0.35[a0];\
                   [1:a]adelay=14700|14700,volume=0.35[a1];\
                   [a0][a1]amix=inputs=2:duration=longest:normalize=0[out]" \
  -map "[out]" -ac 1 -ar 44100 events.wav
```

`adelay` 把每一路定位到对应时刻（毫秒），`amix` 混起来。

频率是手挑的，不是声学设计：低音收、高音起、中频撕裂。
**目标是让观众感到"这里发生了一件事"，不是听出这是什么音。**

---

## 5. 寓言（B）这一路：BGM 怎么对

寓言这套外观通常配用户提供的 BGM。此时的工作变成"对齐"：

| 环节 | 规矩 |
| --- | --- |
| 段落开头 | 对到 BGM 的**小节线**上，不要对到拍点 |
| 最大的揭晓 | 对到**音乐重新进入的那一拍** |
| 音量 | BGM 压到 **-8dB** 左右，别盖住事件音 |
| 没有 BGM | 就明说：成片目前是**无声版**，等配乐 |

"对到小节线而不是拍点"这件事值得多说一句：
拍点是小的时间单位（0.5 秒），小节线是 musically meaningful 的单位（4 拍）。
段落切换落在小节线上，观众感觉是"乐句换了"，而不是"有个东西响了一下"。

---

## 6. 没有 BGM 怎么办

这是一个经常被含糊过去的问题。正确答案很直接：

> **成片先出无声版本（或只有事件音），BGM 后期再配。**

因为 BGM 要按画面的节奏选，而画面的节奏在片子成型之前是不知道的。
反过来做（先定 BGM 再剪画面）会让内容被音乐带跑。

实际流程：

```
画面定稿 → 事件音登记完成 → 出无声版 → 选 BGM → 对齐 → 混音
```

## 7. 版权

| 素材 | 风险 | 建议 |
| --- | --- | --- |
| 代码合成的事件音 | 无 | 放心用 |
| 自己买的 BGM | 看授权 | 确认含自媒体/商用授权 |
| 平台音乐库 | 看平台规则 | 抖音/B 站的音乐库授权范围通常只覆盖站内 |
| 从别的视频里扒的 BGM | **高** | 不要用 |

最后一栏是实测里最常见的翻车点：拿"参考片"的 BGM 用。
片型和音乐风格高度绑定，扒来的音乐在别人的片子里是成立的，
用在自己的片子里，版权和调性都不对。

## 8. 自查

- [ ] 事件音表是从画面登记生成的，不是事后手打的？
- [ ] 提问那镜确实不出声？
- [ ] 每一次画面变化都有对应的事件音？
- [ ] BGM 压到 -8dB 左右，没盖住事件音？
- [ ] 段落开头对到小节线？最大的揭晓对到音乐重新进入的那一拍？
- [ ] BGM 的授权覆盖自媒体发布？

## 9. 和实验的对应

这一章没有配套实验——事件音这条支线在本教程里**还没接进渲染管线**。

分镜表里那一列「声音」就是登记表（noise / split / rise / merge），
但 `film.js` 里没有任何音效实现，成片是**无声版**。
这正好符合第 6 节的取舍：先出无声版，BGM 后期再配。

真要接上去，改动点是清楚的：分镜表登记 → 渲染管线读登记 → 合成音轨 → 混音。
