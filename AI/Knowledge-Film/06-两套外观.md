# 06 · 两套外观：夜曲与寓言

> **这篇要回答**：画面长什么样？颜色怎么用？为什么只有两套？

---

## 1. 只有两套，不是因为懒

拆解市面上的爆款之后，能归纳出两套成熟的外观。
它们不是"风格偏好"，是**两种题材各自的必然解**：

| | **C · 夜曲** | **B · 寓言** |
| --- | --- | --- |
| 适合 | 抽象概念、看不见的机制：数学、信息、物理 | 心理、行为类逻辑 |
| 怎么讲 | 拆成几个当场可演的小实验 | 从动物实验或生活场景讲到"你该怎么办" |
| 视觉基调 | 蓝黑夜空、细星点、暗角 | 纸纹、手绘边框、页码、暖纸色 |
| 字 | 标题用细宋，字幕用无衬线，字少字大 | 手写感标题，正文用衬线 |
| 声音 | **完全由代码合成**：每下变化一声、推拉上滑音、落定低音、提问那镜不出声 | 用户提供 BGM，按小节线对齐段落 |
| 费工 | 低 | **高**（B 最费工） |

判断标准只有一条：**这个概念能不能当场演出来**。

- 傅里叶、信息熵、卷积、为什么天空是蓝的 → 能演 → **夜曲**
- 鸽子的迷信、幸存者偏差、为什么越紧张越做不好、沉没成本 → 要落到生活场景 → **寓言**

**拿不准选 C。**

---

## 2. 为什么"只能选一套"

一部片子只能有一套外观。理由不是审美，是**观众的认知预算**。

观众在前 3 秒就学会了这套片子的语法：
深色背景 = 这是一条知识片；金色 = 关键词；字幕在下面 = 我要读这行字。
学会一套语法之后，观众可以把认知资源全部放在内容上。

中途换一套外观，等于让观众重新学一遍语法——他会以为换了个频道，划走。

所以：**片名卡、结尾卡、字幕样式、背景颗粒，全都算这套外观的一部分**。
不是"主体画面保持一致就行"。

---

## 3. 颜色语义锁定

这是外观里最重要的一条，比配色重要得多：

| 颜色 | 含义 | 全片 |
| --- | --- | --- |
| 金色 | 关键词 | 不破例 |
| 玫红 | 反直觉的点、情绪词 | 不破例 |
| 青色 | 数值与量 | 不破例 |

同一个颜色只表达同一类意思。观众看三秒就学会了"金色 = 关键词"，
之后你必须一直遵守。

破坏这条的后果不是"不好看"，是**观众要把注意力从内容转回"这片子到底想说什么"**。
一部讲傅里叶的片子，如果金色一会儿表示关键词一会儿表示人名，
观众就会开始怀疑自己是不是漏看了什么。

### 两套外观共用同一套颜色语义

换皮不换语法。夜曲是深色底，寓言是暖纸底，
但"金色 = 关键词"这条不变。这样观众的阅读习惯可以在账号内迁移。

---

## 4. 颜色是怎么用起来的

一句话最多染一处。

- 金色染在关键词上：「把它{金色}拆开，里面全是简单的波」
- 玫红染在反直觉的点上：「不[玫红]。任何复杂的东西，都是简单的东西加起来」
- 青色留给数值

染色标记的写法（实验室统一版）：标记**染它前面那一段**，
从上一个句读起的那一段被染色，后面恢复原色。

---

## 5. 外观的物理载体

夜曲这一套的物理载体就是一段代码：

```javascript
const WORLD = {
  bg: '#080c18', bgLift: '#0f1730',
  ink: '#e9e4d6', dim: '#5b6480',
  gold: '#e6c07b', rose: '#e07a8c', cyan: '#7fb4c9',
};
```

星点是带种子的确定性伪随机（见第 7 章），暗角是径向渐变，
颗粒是固定密度的噪点。**常驻元素画在最外层**，
场景只画自己那一层——这样任何一镜都不会把字画进字幕区。

寓言那一套换的是：底色（暖纸色）、字体（手写感标题 + 衬线正文）、
常驻元素（纸纹、手绘边框、页码）、声音（用户提供 BGM）。

---

## 6. 外观是跟着题材走的

有个常见误区：先想好"我要做成夜曲的样子"，再去找能塞进去的题材。

正确顺序是反过来的：

```
选题 → 这个概念能演吗？ → 能演 = 夜曲，不能演但能从生活切入 = 寓言
     → 定外观 → 定颜色语义 → 全片锁死
```

外观在**分镜表之后**才定。因为外观要服务于画面，
而画面要等分镜表写出来才知道长什么样。

---

## 7. 自查

- [ ] 这部片子的题目属于哪种题材？判据说得通吗？
- [ ] 选定的外观和题材匹配吗？
- [ ] 颜色语义表定下来了吗？全片会用同一张表吗？
- [ ] 片名卡、结尾卡、字幕样式都属于这一套吗？
- [ ] 中途有没有"这个场景想换个风格"的想法？（有的话，砍掉）

---

## 8. 和实验的对应

这一章没有配套实验——外观是选题时就定下来的，不是体检项。

颜色语义那条规则目前靠人眼确认：第 11 章的终检把"颜色语义全片一致"
列在**人工确认项**里——说清楚哪些没验过，比假装全过了更有用。

---

**一句话**：外观不是审美选择，是**语法选择**。
观众看三秒就学会了它，之后你必须一直遵守。
