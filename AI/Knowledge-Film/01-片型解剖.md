# 01 · 片型解剖：先把形态量出来

> **这篇要回答**：在做第一条之前，怎么知道"我做的到底是不是那类视频"？
> 靠看片段会骗人——得把形态量出来。

---

## 1. 先分清楚：Vibe 知识不是"AI 做的科普视频"

抖音上"AI 科普"是一大类，但 Vibe 知识是其中很具体的一支。
按公开报道的描述，这类片子的特征是：

| 特征 | 具体表现 |
| --- | --- |
| 画幅 | 16:9 横屏（不是竖屏） |
| 时长 | 2–5 分钟 |
| 声音 | **没有人声**，只有 BGM 和零星音效 |
| 信息通道 | 只有底部一行字幕 |
| 画面 | 不断生长、拆解、重组的文字和图形，没有实拍镜头 |
| 核心机制 | **一句字幕对应屏上一个动作** |

最后一条是全部特征里最关键的一条，也是最难做到的一条。
"计数器真的在数、折线真的在收敛、细胞真的在变形"——
它要求画面不是给字幕配的图，而是字幕本身的动作。

一个反例能说明问题：一句"所以我们知道了熵增定律"，
配一张写着"熵增定律"的图。这是配图，不是演绎。

---

## 2. 量：四条参考片的数据

公开可查的同类实现里，把参考片逐秒量过一遍是这个流程的标准动作：
画幅、帧率、字幕条数、字幕停留时长、语速、片名卡出现位置、
无字幕纯画面的间隔、画与不画的比例。

实验里的 `fixtures/reference.json` 是照这个口径做的一份**教学用样例数据**
（数字是示例值，量法是真的）。跑 `ch01` 会算出这些：

| 指标 | 实测范围 | 变成规矩 |
| --- | --- | --- |
| 分辨率 / 帧率 | 1920×1080 / 30fps | 统一，不要混 |
| 字幕停留中位数 | 3.0–3.8 秒 | 3–5 秒 |
| 语速 | 4.9–6.6 字/秒 | 4.5–7 字/秒 |
| 片名卡首次出现 | 片长的 5%–15% | 5%–30%，第 1 秒绝不出现 |
| 无字幕纯画面 | 18–31 秒 | 每 20–30 秒留一段 |
| 有人声旁白 | 全部没有 | 有人声就不是它了 |

### 为什么是 3–5 秒

这是**读**和**看**的折中。字幕是唯一的信息通道，观众必须读完它，
所以它得够长；但画面在字幕停留期间要发生一件事，
停留太长画面就僵在那里，观众会走神。

低于 3 秒：句子还没读完，画面已经切走了。
高于 5 秒：一句 12 字的话挂在屏幕上一动不动，观众会怀疑片子卡了。

### 为什么语速是 5–7 字/秒

中文正常朗读大约 4–6 字/秒，字幕可以比人读得快一点（观众是"扫"的不是"念"的），
但超过 7 字/秒就成了播报，观众会下意识地放弃跟读。

低于 4.5 字/秒则说明句子写得太长或者太空，需要拆——
注意这个统计要**排除结尾的片名卡**：它是结尾卡，字少停留长，算进去会稀释语速。

## 3. 一条字幕对应一个动作

这是全部指标里最需要单独强调的一条，因为它决定了**写稿的方式**。

传统解说的信息在**声音**里，画面负责佐证。
Vibe 知识的信息在**字幕**里，画面负责**演示**。

于是写作的顺序被倒过来了：

```
传统：先写文案 → 再找配图 → 配音 → 对轴
Vibe：先想画面 → 再写能配上画面的句子 → 排时间轴
```

这不是风格偏好，是**信息通道唯一**的必然结果。
字幕是唯一通道时，屏幕上的画面和字幕说的事情必须是同一件事，
否则观众被迫在两条信息流之间来回切换，认知负荷翻倍。

---

## 4. 三个尺寸档位：画幅不是随便定的

| 档位 | 用途 | 注意 |
| --- | --- | --- |
| 1920×1080 @30fps | 正片 | 主流平台的编码预设都按这个来 |
| 3840×2160 @60fps | 平台要求高码率时 | 渲染时间是 4K 的十几倍，务必先渲片段 |
| 竖屏 1080×1920 | 短视频分发 | **不是这个片型**：字幕区要占 80%–95%，横屏的构图逻辑用不了 |

最后一栏值得多说一句：这个片型是横屏的，因为它的信息密度要求画面能"摊开"。
竖屏版不是把横屏裁一刀那么简单——字幕安全区、构图重心都要重做。
如果要做竖屏分发，更实际的做法是**重做一条竖屏的片子**，而不是裁。

---

## 5. 别一上来就抄片

量形态是为了**排除**，不是为了让你的片子像别人的。

参考片能告诉你的是硬约束（画幅、停留时长、语速区间），
不能告诉你的是选题、形象、节奏的具体安排。
照抄结构而不理解每一步为什么这么安排，做出来就是一条"格式对了但没人看"的片子。

反过来，**不要在量形态之前就开始写稿**。
你在不知道停留时长限制的情况下写出来的稿子，几乎一定太长；
改稿的成本远高于先花十分钟把形态摸清。

---

## 6. 自查

动手前把这张表填一遍，填不满就先别开做：

- [ ] 画幅 / 分辨率 / 帧率定了吗？（1920×1080 / 30fps）
- [ ] 预计时长多少？字幕条数估出来了吗？（2–5 分钟 ≈ 30–60 句）
- [ ] 每句字幕的停留时长打算给多少？（3–5 秒）
- [ ] 片名卡在第几秒出现？（片长的 5%–30%，绝不是第 1 秒）
- [ ] 有没有配乐？（B 路要提前想清楚，BGM 会决定整片节奏）
- [ ] 这条片子是几期的第几期？（决定要不要先锁定角色/风格/用词）
