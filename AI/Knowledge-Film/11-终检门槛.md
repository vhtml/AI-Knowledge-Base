# 11 · 终检：八道门槛

> **这篇要回答**：怎么知道这条片子可以发了？
> 答案不是"看着还行"，是**八道能判的门槛**。

---

## 1. 为什么要有门槛

这类片子的成本结构很特别：**做一条片子要一天，交完就完了**。
没有返工窗口，也没人帮你 review。

所以终检的唯一目的，是在你按下发布键之前，
把那些"观众会发现但你不会发现"的问题拦下来。

而且知识类内容的终检和普通视频不一样：
画面丑一点还能忍，**数据错了就是错**。
所以"事实"和"讲解"两栏的权重最高。

---

## 2. 八道门槛

| 门槛 | 查什么 | 怎么判 |
| --- | --- | --- |
| **讲解** | 成片和分镜表对得上吗？抽五镜过三问都答得出吗？有只是配图的画面吗？屏上的数前后对得上吗？ | 前两条可自动查，后两条要人看 |
| **画与不画** | 提问、命名、结论有没有被硬配图？有没有连着几句画面不变？ | 可自动查 |
| **结构** | 片名在 6–24 秒之间出现？结尾回到开头的画面？最后一屏是片名 + 文献？ | 前两条半自动，最后一条可查 |
| **字幕** | 每句一行？停留 3–5 秒？一句最多染一处？ | 可自动查 |
| **画面** | 字幕区没有别的东西？任何一刻只有一个主体在动？一镜最多一条小字？颜色含义全片一致？ | 前三条半自动，最后一条人看 |
| **节奏** | 没有硬切？主体出完之后停住让人读？每 20–30 秒一段无字幕纯画面？ | 可自动查 |
| **事实** | 屏上每个数字和事实表一致？每个概念有出处？示意的地方写明了？ | 可自动查 |
| **技术** | 确定性检查通过？1920×1080、30fps？没有水印和署名？ | 可自动查 |

每条门槛里，**能自动判的**和**只能人眼确认的**要分开列。
原因见第 4 节。

---

## 3. 三遍看法

终检不是看一遍，是三遍，每遍只做一件事：

### 第一遍：静音，遮住字幕

把声音关掉，把字幕遮住，从头看一遍。

问：**每一段在讲什么，看得出来吗？**

这一遍抓的是"画面只是配图"。如果遮住字幕之后看不懂，
说明画面在重复字幕的话，而不是在演示它。

### 第二遍：只读字幕

关掉画面，只读字幕。

问：**通顺吗？有没有哪句里的名词，屏上找不到？**

这一遍抓的是文案问题：自指、超长、抽象、缺出处。
读起来别扭的地方，就是观众会划走的地方。

### 第三遍：对照门槛

把八道门槛逐条过。这一遍抓的是技术问题：数字对不上、
颜色用错了、有一段画面僵住了、编码参数不对。

## 4. 交片时要说清楚没验过什么

这是终检里最容易被忽略、但最影响信任的一条：

> **交片时把没做到的地方直说——包括"成片我有没有从头到尾看过一遍"。**

为什么？因为自动化检查只能覆盖一部分。
它能验证"字幕停留 3.2 秒"，但验证不了"第 23 秒那根线是不是穿过了字幕区"。

一份诚实的交片说明长这样：

```
已过：八道门槛的自动项全部通过（字幕 / 结构 / 事实 / 技术 / 节奏）
人工项：已静音遮字幕看过一遍；已只读字幕读过一遍；
        "结尾回到开头"这一条确认过
未验：成片没有在手机上完整看过一遍；BGM 版权只覆盖站内使用
```

这种说明看起来像自曝，实际上是**建立信任**：
它告诉对方"你知道哪些地方有风险"。

骗自己说"应该没问题"的片子，最后都是观众替你发现问题——
而且是在评论区。

---

## 5. 自动检查怎么落地

实验室里做成了一个可复用的门槛检查器：

```python
gates = check_all(shots, cues, facts, film_subs, scenes, config, references)
for gate in gates:
    print(gate.name, "✓" if gate.ok else "✗", gate.detail)
```

它的价值不在于"替你看片"，在于**改完之后能立刻知道有没有搞坏**。
改了一句文案、调整了一个场景、换了一套外观之后，
跑一遍门槛检查器，5 秒钟知道有没有破坏别的规矩。

更实用的用法是把它接进 CI 或者本地钩子：
每次提交前跑一次，不通过就不许提交。

---

## 6. 故意做坏的对照

检查器最需要证明的是"它真的能抓到问题"。
所以实验室里会**故意做一个坏片子**（缺三问、停留 1.2 秒、一句话染两处颜色、
没有无字幕段落、事实表里多一个没上屏的数字），然后确认检查器把每一条都报出来。

一个永远报"通过"的检查器比没有检查器更危险。

```bash
cd Demos/examples

```

实验查的是**成片自己**：分镜表和事实表来自 `storyboard.md`，
字幕、场景、配置来自 `film.js`——八道门槛没有一条查的是样例数据。
它会跑完全部门槛、列出人工确认项，然后把片子做坏，验证检查器抓得住。
